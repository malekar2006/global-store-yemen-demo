# Global Store Yemen Demo

نسخة معاينة تجريبية تفاعلية لمشروع **جلوبال ستور** لإدارة بيع وشراء الهواتف وملحقاتها بالجملة والتجزئة.

## ما يتضمنه

- لوحة تحكم عربية RTL متجاوبة.
- نقطة بيع تجريبية.
- إدارة المنتجات والمخزون وIMEI.
- الطلبات والفواتير.
- الضمان والصيانة.
- المحاسبة والعملات.
- إعدادات الفروع والصلاحيات.
- بيانات يمنية افتراضية.

> هذه النسخة Prototype تعمل ببيانات ثابتة داخل المتصفح. لا تمثل نظاماً إنتاجياً ولا تتصل بقاعدة بيانات أو بوابة دفع حقيقية.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## النشر على Vercel

1. افتح Vercel واختر **Import Git Repository**.
2. اختر `malekar2006/global-store-yemen-demo`.
3. اختر الفرع `feature/global-store-demo` للمعاينة.
4. اترك إعدادات البناء فارغة؛ المشروع Static.
5. اضغط Deploy.

## الخطوة التالية للإنتاج

إضافة API وقاعدة بيانات ومصادقة وصلاحيات حقيقية وتدقيق مالي وتكاملات الدفع والشحن، ثم إضافة اختبارات آلية وبيئة staging قبل استخدام بيانات فعلية.
